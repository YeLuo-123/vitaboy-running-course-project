# X5 机器人上位机

机载目录：`/home/wheeltec/x5_http_console`。浏览器打开 `http://192.168.0.108:8080/`。页面使用机载 ROS 2 Humble、Cartographer 和 Nav2；地图保存在 `maps/<名称>/map.yaml` 与 `map.pgm`。

## 操作

1. 点击“启动 Cartographer 建图”，等待雷达、里程计、地图和定位显示“就绪”。
2. 点击“启用键盘控制”，按住 `W/S` 前进/后退、`A/D` 左转/右转（方向键也可用），松开即停。按空格停止运动；点击“结束键盘控制”后小车保持静止。键盘前进限速 0.12 m/s、后退 0.10 m/s、转向 0.35 rad/s。页面失焦或速度指令超时会停车。
3. 带小车缓慢覆盖要建图的区域，回到起点附近，结束键盘控制；填写新地图名，点击“保存当前地图”。旧地图不会被覆盖。保存采用 Nav2 `raw` 文件格式，但将空闲、障碍、未知栅格分别规范成 `0`、`100`、`-1`，供车载 AMCL 正确读取。
4. “开始自主探索”是另一种会驱动车辆的建图方式；只有在安全场地且能使用实体急停时才操作。键盘驾驶与自主探索不能同时运行。
5. 点击“关闭当前模式”，选择保存的地图，再点击“加载地图并启动导航”。
6. 选择“初始位姿”，在地图上点击机器人大致所在区域的中心，选择位置与朝向误差范围后发送。车头方向大致已知时可拖动朝向；选择“约 ±180°”时只需点击。观察紫色 AMCL 粒子是否集中、红色激光点是否落在地图障碍物附近，并核对实体车位置，再选择“导航目标”。
7. “停止运动”取消键盘驾驶、当前目标与探索；“关闭当前模式”同时结束由本控制台启动的 ROS 栈。

## 区域与多点导航

1. 建图结束后先保存地图，关闭建图模式，选择刚保存的地图并点击“加载地图并启动导航”。在地图上设置与小车实际位置一致的初始位姿，等待导航状态就绪。
2. 在“区域与多点导航”中点击“新建区域轮廓”，沿房间边界依次点至少 3 个顶点，填写名称（如“客厅”），点击“保存区域轮廓”。`Shift` 加拖动可平移地图，滚轮缩放；“撤销上一个顶点”可修改草稿。区域标注保存在对应地图目录的 `areas.json`。
3. 选中区域，点击“在地图上设置目标点”，在区域内已知空闲位置点击或拖动以设定朝向，点击“保存区域目标点”。目标点需离未知区域和障碍物至少约 0.15 米。每个区域保存一个目标点。
4. 按期望顺序将区域加入路线，可用“上移”“下移”调整，再点击“按顺序开始导航”。小车通过 USB 声卡离线播报“自主导航开始，目前前往<区域名>”。到达中间目标后播报“已到达<当前区域>，现在前往<下一区域>”，播报结束后静止 3 秒再继续；最后播报“已到达<区域名>，任务完成”。
5. 任务可用“取消多点任务”或页面顶部“停止运动”中止。目标被拒绝、导航失败、语音播放失败、页面断连或导航状态异常时任务停止，不会自动跳过目标。任务执行期间不能修改区域。

语音使用车载 `espeak-ng` 和 `aplay`，默认输出到 USB 声卡 `plughw:CARD=Device,DEV=0`。如声卡标识变化，可为服务设置 `X5_AUDIO_DEVICE` 环境变量。长时间路线需要保持控制页面打开，页面心跳中断超过 3 秒会停止任务。

网页每秒发送心跳。页面失联、雷达或里程计过期、定位丢失时，控制台撤销运动许可；独立的 `velocity_guard.py` 在速度命令过期后发送零速度。软件停止不替代实体急停。

页面页首显示底盘 `/PowerVoltage` 回报的实时电池电压。电压不高于 10.5 V 时提示尽快充电，不高于 10.0 V 时提示可能进入底盘低电压保护；连接或里程计中断时显示 `-- V`。这些提示参考轮趣同类 12 V 底盘的说明，不能当作本车精确的剩余电量百分比或已标定的保护阈值。电压低时若收到运动指令但里程计未动，先充电，再检查电机电源、急停和底盘使能。

导航模式使用车载 Nav2 的 `map_server` 与 AMCL。网页通过 `/initialpose` 发送位置和朝向的高斯先验，默认约 1 m / ±30°，可按实际不确定程度调整；范围不是硬边界。网页直接显示 AMCL `/particle_cloud`、`/amcl_pose` 和变换到地图坐标的实时 `/scan` 端点，不再计算或拦截自定义激光匹配率。紫色粒子表示机器人可能所在的位置，并不表示障碍物；红色激光点才应与墙壁或障碍物大致重合。

设置初始位姿后，网页自动调用 AMCL 的 `/request_nomotion_update`，静止更新最多约 8 秒；若 AMCL 位置标准差已不高于 0.35 m 且朝向标准差已不高于 25°，可以提前结束。该调用不会驱动电机。地图上显示初始范围、粒子云、激光点、估计轨迹和约 2 倍位置标准差范围。定位数值集中仍需现场核对实体车的房间、朝向和红色激光点位置；相似房间可能让 AMCL 收敛到错误位置。导航要求 AMCL 已发布估计且不确定度处于上述范围；运动时持续检查实时定位 TF、雷达和里程计。

## 启动与维护

`x5-http-console.service` 是系统服务，服务启动后保持待机，不自动启动建图或导航。检查：

```bash
systemctl status x5-http-console.service
journalctl -u x5-http-console.service -n 100 --no-pager
```

调试可运行 `./run.sh --dry-run --port 8081`。干运行的速度输出为 `/x5/test_cmd`，不会通过控制台发布到 `/cmd_vel`；`mapping/start` 和 `navigation/start` 仍会启动雷达、底盘驱动与 ROS 进程，因此不要与正式服务同时启动相同模式。

测试：`/usr/bin/python3 test_console.py`。`logs/stack.log` 保存每次 ROS 启动日志。机载原始 `server.py`、`index.html`、`test_console.py` 已备份在 `backups/20261027_before_completion/`。

早期验证覆盖页面接口、实时建图数据链路、地图加载和导航栈就绪条件。导航模式必须由操作者设置与实际位置一致的初始位姿。雷达驱动曾在一次模式切换中崩溃，启动器现会在 5 秒后自动重启雷达节点；若状态持续“等待”，检查 `logs/stack.log`、雷达连接及实体状态。
